Launchkey surface controls

  • Knob 1 scrolls categories (LEADS, PADS-DRONE … EFFECTS).
  • Bottom pads pick an instrument in the category and arm it.
  • Knobs 2–8 set volume, pan and sends. With an EFFECTS bus selected they shape that bus.
  • Categories come from folders inside an INSTRUMENTS folder. The song template has none yet, so only EFFECTS appears (see To-do).

Signal routing

Each instrument track keeps its own dry sound and sends a copy to whichever buses you choose. One reverb on a bus serves every track, so all instruments share one room and the CPU cost stays low.

Bus names must keep the words Cathedral, Bitcrush, Delay, Chorus, Ambient: the Launchkey script finds the buses by those words.

Sending to the EFFECTS folder itself does nothing useful. A folder only sums its own children, so a send has to target each bus.

Starting recipes

Chains read left to right: the instrument and anything that changes its core sound sit on the track, then sends go to buses.

Juno-style dungeon pad

Sunset Circuits (Cosmos) → TAL-Chorus-LX → send: Long Ambient Wash + Cathedral

Slow attack, long release. Cosmos already has bucket-brigade chorus; TAL-Chorus-LX deepens it.

Worn tape melody

Ensoniq SD-1 or OB-Xd 3 → TapeMachine 2 → Tape Echo 2 (Tape Age: Old) → send: Cathedral

The SD-1 needs its ROM files before it makes sound; use OB-Xd 3 until then.

Bard in the tavern

RipplerX (plucked string) or Galician Hurdy-Gurdy → send: Crypt Convolution (low) + Delay

RipplerX models harps, dulcimers and bells physically, so it needs no samples.

Endless drone

Discord Choir chord → render → PaulXStretch → send: Long Ambient Wash

PaulXStretch turns a few seconds into minutes. Use it for transformation, not subtle edits.

War drums in the crypt

Erang Drums & Percussion in drumkv1 → ChowCentaur (light) → send: Crypt Convolution

How-to

Add an instrument track
  1. Click empty space below the tracks, then press Ctrl+T. A selected bus would put the new track inside the EFFECTS folder.
  2. Click the track's FX button and add an instrument.
  3. Arm it (red circle), right-click the arm button → Input: MIDI → Launchkey → All channels, and turn monitoring on.
Send a track to the buses
  1. Click the track's ROUTE button → Add new send → pick a bus.
  2. Start the send fader around −12 dB and adjust by ear.
  3. Faster: drag from the ROUTE button onto the bus track.
  4. For a fully crushed or warbled sound, put the plugin on the track instead of sending.
Change a toolbar icon
  1. Right-click empty toolbar space → Customize toolbar.
  2. Select a button → Icon… → Change icon.
  3. Filter by RIPO, RT_Synthwave (or any RT color), c_, or a word like marker.
  4. Preview all RT colors in Data/toolbar_icons/!Preview_Icons.png.
Load a MIDI colormap
  1. Preferences → MIDI Editor → Default color map → Browse.
  2. Choose a file in ~/.config/REAPER/Data/color_maps/ (Forest, Vintage, Shadow and others).
Install a Reapertips color toolbar
  1. Actions → Show action list → Key map… → Import → KeyMaps/Color Toolbar Actions.ReaperKeyMap, choosing merge.
  2. Options → Customize menus/toolbars → Import → MenuSets/Color Toolbar.ReaperMenu onto an unused floating toolbar.
  3. View → Toolbars → that toolbar. The swatches use the Reapertips palette.
Install new native plugins later
  1. Check the repos first: pacman -Ss name, then the AUR with yay -Ss name.
  2. For a download, copy the .vst3 bundle into ~/.vst3. One format per plugin keeps the FX list tidy.
  3. REAPER rescans on startup, or use Preferences → Plug-ins → VST → Re-scan.
Kontakt and other Windows plugins

Kontakt was installed and then removed: inside REAPER under Wine its clicks landed about 240×170 pixels away from the pointer. All Windows plugins were then disconnected. If one is ever needed to render an old part (Zither in motd1-instruments), yabridgectl can bring it back temporarily while ~/.wine still exists.
